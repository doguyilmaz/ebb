# ebb Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ebb`, a fast macOS disk analyzer and safe cleaner: one Go binary (CLI + 127.0.0.1 API + embedded/hosted web UI + MCP + daemon) that explains where space went and why, and reclaims it through reviewed plans.

**Architecture:** A cgo `getattrlistbulk` walker feeds a pointer-free arena tree through a single builder goroutine. Detectors and data rules turn the tree, volume accounting and external tool output (`simctl`, `diskutil`, …) into findings. A shared `internal/app` facade serves the CLI, the HTTP API (lockstep's server/pairing/SSE patterns) and the MCP server. The React UI renders canvas charts from level-of-detail slices.

**Tech Stack:** Go 1.26 (cgo on darwin), cobra, go-toml/v2, doublestar/v4, testscript; Bun, Vite 8, React 19, TanStack Router/Query, radix-ui, cmdk, lucide-react, @tanstack/react-virtual, d3-hierarchy, d3-sankey, zustand, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-ebb-design.md` (read it before starting; section refs below are `§n`).

## Global Constraints

- cgo only in `*_darwin.go`, `*_darwin.c`, `*_darwin.m` (+ headers); every darwin feature has a `!darwin` fallback that builds with `CGO_ENABLED=0`.
- Go dependencies allowed: `github.com/spf13/cobra`, `github.com/pelletier/go-toml/v2`, `github.com/bmatcuk/doublestar/v4`, `github.com/rogpeppe/go-internal` (tests). Anything else → add a Deviations entry first.
- UI dependencies: lockstep's set (`ui/package.json` there) + `d3-hierarchy`, `d3-sankey`, `zustand`; dev: `playwright`. Bun only (`bun install`, `bun run`, `bun test`, `bunx`).
- Paths: config `~/.config/ebb/config.toml`, user rules `~/.config/ebb/rules/*.toml`, state `~/.local/state/ebb/`. `EBB_HOME` re-roots both; `EBB_SANDBOX=1` blocks destructive actions, trash, OS service commands and external tool commands except an allowlist of read-only ones in tests.
- Constants: default port `47340`; launchd label `dev.ebb.daemon`; hosted origin `https://ebb.apps.doguyilmaz.com`; small-file threshold 1 MiB; large file 1 GiB; stale after 30 days; snapshot dir minimum 10 MB; snapshot retention last 60 + one per ISO week; plan expiry 10 min; pair window 5 min, 6-digit code, 5 attempts; low-space alert 10 GB; body limit 1 MB; MCP `protocolVersion "2025-06-18"`.
- Default scan root: `/System/Volumes/Data` when it exists, else `/`. Never cross mount points, never follow symlinks.
- Code style: match lockstep; no debug prints; comments only for non-obvious logic or warnings; no fix-story/task-id comments.
- English UI strings and docs.
- **Never delete anything real during development.** Destructive code paths are exercised only under `EBB_SANDBOX=1` in temp dirs. Real-machine runs are read-only scans unless the user approves an action.
- After every task: `make check` green, tick the task's boxes in this file, commit with a one-line plain sentence (lockstep style, e.g. "Add arena tree with size propagation"), no body, no trailers, user's git identity.

type Kind uint8
const (KindDir Kind = iota; KindFile; KindLink; KindOther; KindSmall /* virtual node in slices only */)

type Flag uint8

	FlagShared   Flag = 1 << iota // hardlink counted at another location
	FlagClone                     // EF_MAY_SHARE_BLOCKS
	FlagMount                     // mount point, not descended
	FlagDenied                    // directory could not be read
	FlagSyncRoot                  // iCloud sync root
	FlagProject                   // directory contains a project marker file

type Node struct {
	ID, Parent       ID
	Name             string

	Logical          uint64
	Files            uint32 // regular files in subtree, small ones included
	MaxMtime         int64  // unix seconds, newest in subtree (dir mtime included)
	OwnMtime         int64  // newest among the dir's own files and the dir itself
	SmallCount       uint32 // files below the threshold folded into this dir
	SmallAlloc       uint64
}

func (w *Writer) SetFlags(id ID, f Flag)

type Options struct {
	Root           string
	Threads        int    // 0 → min(8, runtime.NumCPU())
	Gentle         bool   // IOPOL_THROTTLE instead of IOPOL_UTILITY

	"settings.gradle", "Podfile", "pubspec.yaml", "pyproject.toml", "requirements.txt", "Gemfile", "composer.json"}

	Path    string

}
type Problem struct{ Path, Err string }
type Result struct {
	Tree     *tree.Tree
	Problems []Problem
	Elapsed  time.Duration
	Dirs, Files uint64
}
type Session struct{ /* … */ }
func Start(ctx context.Context, opt Options) (*Session, error) // error only for an unreadable root
func (s *Session) Tree() *tree.Tree      // live; readers are safe during the scan
func (s *Session) Progress() Progress
func (s *Session) Wait() (*Result, error) // ctx.Err() when cancelled
func Scan(ctx context.Context, opt Options, every time.Duration, fn func(Progress)) (*Result, error)

Internals:

```go
type entry struct {
	nameOff uint32
	nameLen uint16
	kind    tree.Kind
	mount   bool
	alloc, logical, private uint64
	mtime   int64
	nlink   uint32
	ino     uint64
	flags   uint32 // st_flags (SF_DATALESS = 0x40000000)
	ext     uint32 // EF_* flags
}
type batch struct {
	dir     tree.ID
	path    string
	entries []entry
	names   []byte
	err     error
}
type reader interface{ readDir(path string, b *batch) error }
```

Flow: queue of `job{path string; dir tree.ID}` (mutex + cond, LIFO). Workers pop, `readDir` into a pooled batch, send to `batches` (buffer 256). The builder goroutine owns all tree writes: per batch, one `tree.Write`; subdirectories → `AddDir` + push job; files ≥ threshold → `AddFile` (after `Link` when `nlink > 1`); smaller files folded into one `AddSmall`; marker names set `FlagProject`; mount points get `FlagMount` and are not queued; dataless files count zero bytes; errors → `Problem` + `FlagDenied`. `pending` (builder-only counter) starts at 1, `+= subdirs`, `-= 1` per batch; at 0 the queue closes. Unique bytes = `private` when `ext&EF_MAY_SHARE_BLOCKS != 0` and the reader filled it, else alloc. Progress counters are atomics.

Generic reader: `os.ReadDir` + `os.Lstat` → `syscall.Stat_t` (`Blocks*512`, `Size`, `Nlink`, `Ino`, `Mtimespec`/`Mtim`); mount points detected by `Dev` differing from the parent's.

   names capacity >= attrbuf size. */

Map `VREG→1, VDIR→0, VLNK→2`, others → 3. Go opens the directory with `syscall.Open(path, O_RDONLY|O_DIRECTORY|O_CLOEXEC, 0)` and loops `ebb_bulk` until 0; names are appended to `batch.names` with offsets rebased.
