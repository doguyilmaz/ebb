# ebb open: one command to start ebb and connect the window

> Steps use checkbox (`- [ ]`) syntax for tracking. Same constraints as `2026-10-17-ebb.md` (make check green, one-line commits, writing rules for public text).

**Goal:** Replace the 6-digit pairing code with a link the CLI opens. `ebb open` starts ebb when needed (offering the background service once), mints a one-time key and opens the hosted page with it. The page claims a token with the key and goes straight to the app.

**Decided (user, 2026-10-19):** no confirm button on the page (running the command is the consent); the background prompt defaults to yes; the code flow goes away.

## Flow

1. `ebb open [origin]`
   - Running ebb (`server.Live`): use it. A daemon older than this CLI (`Status.Daemon`, versions differ, CLI not `dev`) is restarted once with `launchctl kickstart -k`.
   - Not running, service installed: kickstart it (bootstrap again when it is not loaded), wait up to 15 s for `server.Live`.
   - Not running, no service, TTY: `Keep ebb running in the background and start it at login? [Y/n]`. Yes installs the service. No serves in this terminal like `ebb serve` and says closing it stops ebb.
   - Not running, no service, no TTY: error naming `ebb daemon install` and `ebb serve`.
2. Target: the given origin, else the first allowed origin (the hosted page by default). The local window (`#token=`) instead when no origin is allowed or the default browser is Safari (LaunchServices `https` handler via `plutil`; unknown counts as Safari, since the local window works everywhere).
3. Hosted: `app.IssueLinkKey(origin)` stores a hash in `link-keys.json` (5 minutes, single use) and the CLI opens `<origin>/#key=<key>&port=<port>`. It also prints the link for another browser.
4. Page: reads `key` and `port` from the hash and strips them, `POST /api/v1/pair {key}` with its Origin, stores the token. Another open tab picks the token up from localStorage (`storage` event).

## Edge cases

- ebb stops later: a page that has a token shows "ebb is not running" with `ebb open` and reconnects by itself; no new pairing.
- Token revoked (`ebb web deny`): 401, back to the connect state.
- Link expired, used or from history: token present → fine; else the connect state notes the link expired.
- Older ebb than the page while unpaired: the command becomes `brew upgrade ebb && ebb open`.
- Other browser than the default: paste the printed link within 5 minutes.
- Link opened on another device: loopback is unreachable there; the key is useless.
- Self-hosted copy: `ebb web allow <origin>` then `ebb open <origin>`.
