# ebb.app: an app identity for privacy settings, Login Items and notifications

> Steps use checkbox (`- [ ]`) syntax for tracking. Same constraints as `2026-10-17-ebb.md`.

**Problem:** ebb ships as a bare binary in a versioned Homebrew folder. macOS therefore knows it by path: Full Disk Access is lost on every upgrade, privacy settings show a generic icon, Login Items shows the signer's personal name, and `osascript` notifications belong to Script Editor (a click opens an empty script). Without Full Disk Access a first scan also triggers one prompt per protected folder.

**Goal:** ship `ebb.app` (LSUIElement, icon `assets/brand/ebb-spectrum.icns`, bundle id `com.doguyilmaz.ebb`) with the same binary inside, installed to /Applications by the cask, with `ebb` on PATH from inside the app. The background service runs the app's executable, so macOS attributes it to the app: one Full Disk Access entry that survives upgrades, the app's name and icon in Login Items, and notifications from ebb itself.

## Decisions

- GoReleaser OSS cannot build, sign or notarize an app (`app_bundles`, `notarize.macos_native` and the cask `app:` field are Pro). `scripts/macapp.sh` runs as the `universal_binaries` post hook: it builds the bundle, signs it with the Developer ID from the existing secrets, notarizes and staples it. The archive carries `ebb.app` next to the bare binary; the cask gets `app "ebb.app"` through `custom_block` and `binary "#{appdir}/ebb.app/Contents/MacOS/ebb"`.
- The LaunchAgent points at the app's real executable (stable across upgrades) and names the app with `AssociatedBundleIdentifiers`.
- Full Disk Access first: the welcome screen asks for it before the first scan, names exactly what to turn on (ebb in the list when the service scans, the terminal when ebb runs in one) and continues on its own once granted. "Scan without it" lets macOS ask per folder.
- Homebrew still removes the service on every upgrade; the existing postflight `ebb daemon restore` brings it back.
- Existing users grant Full Disk Access once more: the grant moves from a path to the app.
